# SpendingFortune

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
어제 지출을 입력하면 오늘의 소비운세와 절약 조언을 리워드 광고 시청 후 알려주는 매일 콘텐츠

## Problem
운세 콘텐츠(자몽다)와 가계부 콘텐츠는 각각 검증됐지만 둘을 결합한 시도는 없다. 매일 켜는 습관형 콘텐츠가 필요한데, 순수 가계부는 토스 본체 기능과 겹쳐 서드파티가 밀리기 쉽다.

## Target Users
재테크에 관심 있고 가벼운 운세 콘텐츠도 즐기는 2030 토스 유저

## Core Features
1. 어제 지출 카테고리/금액 간단 입력 (수동, localStorage)
2. 오늘의 소비운세 텍스트+이미지 (매일 갱신, 리워드 광고 후 공개)
3. 지름신 주의보 — 과소비 카테고리 감지 알림
4. 12유형 소비운세 캐릭터
5. 결과 공유 카드
6. 7일 소비운세 히스토리 그래프

## Monetization
- Model: ads
- Estimated MRR: $321
- Reasoning: DAU 4,500 가정(매일 콘텐츠 갱신 습관) — 리워드+배너 결합 월 약 434,000원(수수료 반영). '결과 게이팅+일일체크인' 두 고수익 패턴을 동시에 충족.
